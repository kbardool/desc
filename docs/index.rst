desc 3.0 runs on PyTorch and requires Python 3.14 or newer. Existing calls such as
``desc.train(adata, ...)`` work unchanged. desc 2.0.3 (TensorFlow 1) and desc 2.1.1
(TensorFlow 2) remain available for TensorFlow users. See `Installation <https://eleozzr.github.io/desc/installation.html>`__.

Report issues and see the code `here <https://github.com/eleozzr/desc>`__.
If desc is useful for your research, consider citing `*** (2019)`__.
